# Leagues, seasons, relegation, trophies

**Ladder (top to bottom):** C2 Champions League · C1 Europa League · B2 Bundesliga · B1 2. Bundesliga · A2 DFB-Pokal · A1 3. Liga.

**League Points (LP)** = squad value + form + bonuses.
- *Squad value*: each word counts by stage (new 0, learning 0.3, young 0.7, mastered 1). A grammar item counts 2.5 words.
- *Entry thresholds* (word equivalents, loosely following Goethe/CEFR vocabulary estimates): 3. Liga 0 · DFB-Pokal 650 · 2. Bundesliga 1300 · Bundesliga 2400 · Europa League 3500 · Champions League 6500.
- *Form* (−150…+300) changes every matchday (one ISO week): win +30 (+40 if you practised all 7 days), draw 0, loss −25 (under 50% of the weekly target), no-show −50. The very first week never costs points.
- *Bonuses*: season exam grades (gold +60, silver +40, bronze +20).

**Season** = 4 matchdays. At the final whistle: LP at or above the next threshold = promotion; LP more than a small buffer below your own league's threshold = relegation; otherwise you stay. The weekly target is 5 × your daily goal; you need 4 active days for a win.

**Trophies:** season exam ("Saisonfinale", 20 questions, 70/80/90% for bronze/silver/gold), promotion trophy, title trophy (3+ wins and no loss in a season). All are in the cabinet (Table → Trophy cabinet). Missed exams can be played for two seasons.

**Football statistics:** shots = answers, goals = right first time, on target = goals + near misses, xG = sum of (right+1)/(right+wrong+2) per card before the answer, clean sheets = error-free sessions, minutes = time spent.

**Language:** Settings → Sprache / Language (English or Deutsch). Card data (your words) is never translated.
